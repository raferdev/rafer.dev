Every page here is a file under `origin/`. Folders become routes, and the
sidebar is generated by walking that tree — there is no navigation list to keep
in sync.

## How routing works

A file's path is its URL, minus any ordering prefix.

| File                                       | URL                        |
| ------------------------------------------ | -------------------------- |
| `origin/index.mdx`                         | `/`                        |
| `origin/01-getting-started/02-install.mdx` | `/getting-started/install` |
| `origin/03-blog/index.mdx`                 | `/blog`                    |

## Ordering

Each folder chooses how its children are sorted by dropping a `config.yml`
beside them. The three sections in this sidebar each use a different strategy.
