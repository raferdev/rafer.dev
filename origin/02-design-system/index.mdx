This folder sets `ordering: alphabetical`, so its pages sort by title no matter
what the filenames are. Useful for reference material where there is no
narrative sequence.

## Live components

Because pages are MDX, a component can be rendered rather than described:

<Button>A real button</Button>

The same import you would write in a route works here.
